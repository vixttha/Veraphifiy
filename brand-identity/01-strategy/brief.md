# Strategy and creative brief

**Category.** Code memory for coding agents, organized by project version. Veraphify pairs each archived version with a Graphify map tied to its source commit. An agent can choose the version it needs and trace a feature to its implementation, relevant tests, and verification receipts.

**Audience.** Coding agents navigating a specific project version, maintainers preserving knowledge across releases, and contributors reviewing a change. Lead the walkthrough with the version, then show how to open its map, inspect the committed source, and find the verification record.

**First placement.** GitHub README on light and dark themes. Give the name and factual descriptor in real text. The symbol should also work on its own as an avatar at 24 px.

| Quality | Design implication |
| --- | --- |
| Traceable | Use a continuous path with an explicit origin and destination. Carry real file and line labels into examples. |
| Precise | Use deliberate alignment, few shapes and generous whitespace. Set source anchors in a monospaced face. |
| Independent | Use a graphite, paper and copper palette and an original silhouette. Credit Graphify Labs in the integration copy. |
| Practical | Lead with one inspectable example. Keep the name readable in prose and the symbol legible in a narrow README. |

- [BART evidence archive, v0.0.8](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/6af3c2025be3f51e02dca4e4502088c526aae6d1/graphify/v0.0.8) is the pinned version-specific graph and receipt example. Its receipt records the source commit and MCP verification result.

- [Graphify Labs upstream](https://github.com/Graphify-Labs/graphify) supplies the engine. Use its repository as a comparison for naming and mark similarity and as the source for attribution.

**Owner direction.** The owner locked [Veraphify](../02-naming/naming.md) as the product name and chose the Graphify wordplay because Graphify is central to the product. Veraphify makes Graphify easier for coding agents to use by giving them the map for the project version they are working on. Public copy credits and supports Graphify and states that Veraphify is developed and maintained independently of Graphify Labs.

**Working proposal.** Lead with the [Filed Edge](../04-logo/logo.md) symbol. In the first example, show the project version alongside the file, test, or receipt that an agent follows from the map.
