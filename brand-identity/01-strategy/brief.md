# Strategy and creative brief

**Category.** A GitHub repository evidence kit that uses Graphify to map shipped features back to source, tests, and verification records. Start with a feature, follow its graph links, and identify the commit and source location behind the claim.

**Audience.** Maintainers adopting the kit, contributors reviewing a change, and agents navigating an unfamiliar repository. Their first decision is whether the project gives them a practical way to trace a claim, inspect the underlying source, and check the run that produced the evidence.

**First placement.** GitHub README on light and dark themes. Give the name and factual descriptor in real text. The symbol should also work on its own as an avatar at 24 px.

| Quality | Design implication |
| --- | --- |
| Traceable | Use a continuous path with an explicit origin and destination. Carry real file and line labels into examples. |
| Precise | Use deliberate alignment, few shapes and generous whitespace. Set source anchors in a monospaced face. |
| Independent | Use a graphite, paper and copper palette and an original silhouette. Credit Graphify Labs in the integration copy. |
| Practical | Lead with one inspectable example. Keep the name readable in prose and the symbol legible in a narrow README. |
