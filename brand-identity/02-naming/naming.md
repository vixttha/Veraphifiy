# Naming

**Working recommendation.** Edge Docket (ej DOK-it). Use the exact spelling for the product and wordmark in the [creative decision](../01-strategy/creative-decision.json). The name preserves the idea of a place to go when you need answers about a repo. The descriptor gives readers the category on first contact.

| Candidate | Three connections to the project | Trade-off |
| --- | --- | --- |
| **Edge Docket** | An edge is a relationship in the graph. A docket is an indexed record you can return to. Together they suggest that a graph relationship can lead to its supporting source and verification. | “Docket” can sound legal. Lead with “Repository evidence kit” in the README. |
| **Trace Cairn** | A trace follows a documented relationship. A cairn marks a point on a route. Its stacked stones suggest successive, retained checkpoints. | “Cairn” may need a pronunciation cue (kairn), and it already appears in adjacent developer tooling. |
| **Source Waymark** | “Source” names the committed evidence. A waymark guides readers from a feature to its implementation. A physical mark implies a place others can revisit. | The name is longer, and Waymark is already used in tooling for coding agents. |

## Name screening

Initial public screen on November 19, 2026. Scope was GitHub repository names and public web results for the English-language developer tool. Searches covered spaced, joined and hyphenated forms. This is a creative similarity screen with clearance pending.

| Candidate | Queries | Observed result |
| --- | --- | --- |
| Edge Docket | `"Edge Docket"`, `"EdgeDocket"`, `"edge-docket"` | No matching developer project surfaced in the results reviewed. Keep the full two-word name. |
| Trace Cairn | `"Trace Cairn"`, `"TraceCairn"`, `"trace-cairn"` | Exact candidate did not surface in the results reviewed. Adjacent use of Cairn includes [Cairn Code](https://github.com/cairn/cairn). |
| Source Waymark | `"Source Waymark"`, `"SourceWaymark"`, `"source-waymark"` | Exact candidate did not surface in the results reviewed. [Waymark](https://github.com/waymarks/waymark) already serves developers working with coding agents. |
| Graphify HQ | `"Graphify HQ"`, `"Graphify Labs" Graphify` | The leading word is the complete name of the upstream product. A reader can plausibly read “HQ” as its official workspace. [Upstream product identification](https://graphify.com/blog/what-is-graphify) |

## Usage

- **Product and wordmark.** Edge Docket is the recommendation. Keep “Repository evidence kit” as separate descriptor text.
- **Upstream attribution.** “Built with Graphify, the code knowledge graph from Graphify Labs.” Link Graphify to the [upstream repository](https://github.com/Graphify-Labs/graphify).
- **Historical label.** “Graphify HQ” identifies the existing repository and archived work while the new name is under review. A slug or identifier migration is a later owner decision.
