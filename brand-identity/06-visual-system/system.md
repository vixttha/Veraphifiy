# Visual system

The proposed palette pairs paper and ink with a copper accent for the source or receipt reference. Use a restrained surface with margin space around the mark. The same semantic roles carry through both themes.

| Role | Light theme | Dark theme | Contrast on theme surface |
| --- | --- | --- | --- |
| Surface | Paper `#FAF7F0` | Ink `#192522` | |
| Primary text and mark | Ink `#192522` | Paper `#FAF7F0` | 14.77:1 in each theme |
| Secondary text | Slate `#4B5D57` | Sage gray `#B4C3BC` | 6.54:1 light and 8.63:1 dark |
| Evidence accent | Copper `#7B351F` | Light copper `#FFAB85` | 8.28:1 light and 8.59:1 dark |

Ratios use relative luminance of the listed hex pairs. Underline text links and include text labels for verification states. GitHub controls README text and link colors. Apply the palette to controlled artwork and documentation surfaces.

**Type.** Instrument Sans semibold is the wordmark candidate. Use the GitHub default system sans for Markdown body copy, with system monospace for paths, SHAs and excerpt labels. For controlled documentation, use Instrument Sans or the system sans with `ui-monospace` for code. Record the license and version of any font file added to the repository.

**Graphics.** Use a small source-backed example with a feature, a relationship, a file and line, and a receipt reference. Label the endpoints directly. The [pinned BART archive](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/6af3c2025be3f51e02dca4e4502088c526aae6d1/graphify/v0.0.8) is the first candidate for an example. Light and dark versions use the same geometry and hierarchy.
