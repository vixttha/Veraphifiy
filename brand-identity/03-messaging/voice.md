# Slogan and voice

**Lead slogan.** A map with receipts.

**Descriptor.** A repository evidence kit built with Graphify.

**README opener.** “Find the source behind a feature. Follow its graph links to code, tests and verification records tied to a commit.”

| Slogan option | Three readings |
| --- | --- |
| **A map with receipts.** | The map shows relationships. The receipt records verification. The two together let someone else check what the map represents. |
| **Follow it to the source.** | Start from a feature and follow a graph relationship. Open the original code at the cited line. Use the exact commit as the reference when verifying a claim. |
| **Every link leads somewhere.** | A graph link reaches another entity. A source link can be opened and inspected. An evidence link gives a reviewer somewhere concrete to go next. |

Use the lead slogan in an overview if it helps orient readers. Use the factual descriptor for repository descriptions and the headline for documentation. Write short sentences that lead with the result, then identify the evidence.

- **Example guidance.** “Start with the pinned BART graph and open its companion receipt.”
- **Example status copy.** “The receipt records a different source commit. Compare its SHA with the graph before using this evidence.”

The [pinned evidence archive](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/tree/6af3c2025be3f51e02dca4e4502088c526aae6d1/graphify/v0.0.8) shows a graph paired with a receipt. The [Test Vault record](https://github.com/vixttha/Graphify-HQ/blob/3651503ad22a9db480dc8eb31c17599803f35ae8/test-vault/README.md) documents the verification scope. Use examples with an inspectable source. Phrase test links as test definitions unless a run receipt records the result.
