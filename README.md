# Veraphifiy Brand Identity

Veraphifiy is an independent repository evidence kit built with Graphify. It links features to source, tests, and verification records. Start with the [brand brief](brand-identity/01-strategy/brief.md) and [naming record](brand-identity/02-naming/naming.md).

The [Brand Identity kit](brand-identity/README.md) was copied from [Brand Identity Template at `5930c91`](https://github.com/vixttha/Brand-Identity-Template/tree/5930c91a1b89cbb2bcdb072df4c74002675343b7/brand-identity), the merged revision after the [v0.0.2 release](https://github.com/vixttha/Brand-Identity-Template/releases/tag/v0.0.2).
