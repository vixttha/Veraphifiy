# Veraphifiy Brand Identity

Veraphifiy gives coding agents **a code memory for each project version**. Each archived version has its own Graphify map tied to its source commit. An agent can start with the version it is working on, look up how its features work, and follow the evidence to source code, tests, and verification records.

We use and support the open-source Graphify project. Veraphifiy is developed and maintained independently of Graphify Labs. [Graphify upstream repository](https://github.com/Graphify-Labs/graphify)

Start with the [brand brief](brand-identity/01-strategy/brief.md) and [naming record](brand-identity/02-naming/naming.md).
