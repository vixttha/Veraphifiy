# Graphify HQ language audit

The audited checkout is [ffae26b](https://github.com/vixttha/Graphify-HQ/commit/ffae26b413780ad52d8ae342df97aac2cde930d0). The [public workflow](https://github.com/vixttha/Graphify-HQ/actions/runs/44518123477) completed successfully. Its logs account for 66 named results on Ubuntu and 11 on Windows. The Ubuntu handoff recorded identical graph SHA-256 values from Python and Node and a passing Lydite v2 verdict for the exact audited checkout and run.

The audit compared the executable case catalog, test sources, runner reconciliation, producer and consumer behavior, and Lydite inventory. The local inventory reports one generic sample in each of 14 language folders. The installed catalog validator, receipt verifier, and Git source helper are byte-identical to the [pinned Lydite starter](https://github.com/vixttha/Lydite-Test-Vault-Template/tree/87d25d80d3154d295052412b64b29a0f0f152c27/starter/test-vault). The [pinned Lydite run](https://github.com/vixttha/Lydite-Test-Vault-Template/actions/runs/44506598515) is evidence for the upstream tool revision.

## Reproduced gaps

Local probes used disposable fixtures, including temporary copies of the known-good Python handoff. The provenance probe used the byte-identical pinned BART verifier with simulated GitHub responses. Mutated graph fixtures received matching graph digests and updated counts where relevant, so they exercised the targeted checks independently of the existing digest and count checks. The unchanged controls passed.
