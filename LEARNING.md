# README technique learning log

This log records approaches selected for Veraphify’s `v0.0.9` homepage trial. README HQ `v0.0.6.67` provides a shared [technique registry](https://github.com/vixttha/README-HQ/blob/8d50caec2bc6fcb998994a1fd302294a029325f9/techniques/registry.json) and a [learning intake](https://github.com/vixttha/README-HQ/blob/8d50caec2bc6fcb998994a1fd302294a029325f9/learning/README.md) for evidence tied to exact public Git sources. The observations here inform the local plan. A reproducible public trial can supply the measured outcomes for a later intake receipt.

The first and third rows reinforce the product’s value together. The example makes the citation tangible. The evidence route lets a reader establish which revision and test produced it. Use the second row beside the quickstart and the fourth to decide what belongs on the homepage.

## Veraphify preview trial observation

The [README draft](https://github.com/vixttha/Veraphify/pull/55) pairs a relative verification guide with commit-pinned product records and exact runner evidence. The guide gives the expected two-version citation results, separates Linux walkthrough coverage from Windows replay coverage, and records a rerun path alongside the artifact ID and digest. The [public Ubuntu run](https://github.com/vixttha/Veraphify/actions/runs/44642589173/attempts/1) confirmed exact-tree navigation and independently executed the draft’s quickstart and the pinned walkthrough. Graphify MCP resolved the same README revision’s claim and proof anchors. Reader behavior and GitHub viewport layout remain unmeasured in this trial.
